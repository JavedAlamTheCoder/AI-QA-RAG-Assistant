# Bug Report Format

## Standard Bug Report Template

### Bug ID
Example: BUG-001

### Title / Summary
Short and clear issue summary.

Example:
Login page shows incorrect error message for invalid password.

### Module
Example:
Login Module

### Environment
- Application URL:
- Browser:
- Operating System:
- Build Version:
- Test Environment:
- Device:

### Severity
- Blocker
- Critical
- Major
- Minor
- Trivial

### Priority
- High
- Medium
- Low

### Preconditions
Mention required setup before reproducing the issue.

Example:
User should be registered with a valid email address.

### Steps to Reproduce
1. Open application URL
2. Go to Login page
3. Enter valid email
4. Enter invalid password
5. Click Login button

### Expected Result
System should display a proper validation message:
“Invalid email or password.”

### Actual Result
System displays:
“Something went wrong.”

### Test Data
Email: testuser@example.com  
Password: Wrong@123

### Attachment
- Screenshot
- Video recording
- Console logs
- API response
- Network logs

### Status
New / Open

### Assigned To
Developer name or team

### Reported By
QA Engineer name

### Reported Date
Mention the date when the issue was reported.

---

## Example Bug Report

### Bug ID
BUG-LOGIN-001

### Summary
Login page accepts invalid password and redirects user to dashboard.

### Module
Authentication

### Environment
- URL: https://JavedAlam.com/login
- Browser: Chrome
- OS: Windows 10
- Build: v1.0.4
- Environment: QA

### Severity
Critical

### Priority
High

### Preconditions
User account should exist in the system.

### Steps to Reproduce
1. Open login page
2. Enter valid email
3. Enter invalid password
4. Click Login
5. Observe the result

### Expected Result
User should not be logged in. System should show an invalid credential message.

### Actual Result
User is redirected to dashboard.

### Status
New

# Test Case Document

## Test Case Writing Guidelines
A good test case should be simple, clear, reusable, and easy to execute.

## Test Case Template

| Field | Description |
|---|---|
| Test Case ID | Unique ID of test case |
| Module | Feature or module name |
| Scenario | What needs to be tested |
| Preconditions | Required setup before execution |
| Test Steps | Step-by-step execution details |
| Test Data | Data used during testing |
| Expected Result | Expected system behavior |
| Actual Result | Actual system behavior |
| Status | Pass / Fail / Blocked / Not Run |
| Priority | High / Medium / Low |
| Remarks | Additional comments |

## Sample Test Cases

### TC_LOGIN_001 – Verify login with valid credentials
Module: Login  
Precondition: User should be registered.  
Steps:
1. Open login page
2. Enter valid username
3. Enter valid password
4. Click Login

Test Data:
Username: Javed@example.com  
Password: Javed@123

Expected Result:
User should be logged in successfully and redirected to dashboard.

Status:
Pass / Fail

---

### TC_LOGIN_002 – Verify login with invalid password
Module: Login  
Precondition: User should be registered.  
Steps:
1. Open login page
2. Enter valid username
3. Enter invalid password
4. Click Login

Expected Result:
System should display an invalid credential error message.

---

### TC_SIGNUP_001 – Verify signup with valid data
Module: Signup  
Steps:

4. Enter valid password

### TC_SEARCH_001 – Verify product search functionality
Module: Search  
Steps:
1. Login to application
2. Enter product name in search box
3. Click Search button
4. Observe search results

Expected Result:
Relevant products should be displayed.

---

### TC_CART_001 – Verify add to cart functionality
Module: Cart  
Steps:
1. Login to application
2. Search for a product
3. Click Add to Cart
4. Open cart page

Expected Result:
Selected product should be visible in the cart.

## Test Execution Status
- Pass: Actual result matches expected result
- Fail: Actual result does not match expected result
- Blocked: Test cannot be executed due to dependency
- Not Run: Test is not executed yet

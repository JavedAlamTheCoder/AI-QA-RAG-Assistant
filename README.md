## Workflow Overview

This project demonstrates how AI Agents can retrieve QA/testing knowledge from a Vector Store using RAG architecture and generate intelligent responses in real time.

The workflow includes:

1. Uploading QA knowledge documents
2. Creating embeddings using Ollama
3. Storing embeddings in Vector Store
4. AI Agent retrieving relevant knowledge
5. Groq LLM generating final responses
